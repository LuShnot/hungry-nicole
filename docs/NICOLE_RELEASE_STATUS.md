# Seedance 妮可 0.10.0 发布检查

目标：`heyuyang04-ui/hungry-nicole`。本轮仅发布 Seedance 连续视频版的源码与素材包；旧独立生图版已从当前项目移出，保留本地归档，不重新发布。

## 验收范围

- 用户已经确认当前视频动作效果可用，并授权上传。
- 27 段素材全帧解码通过：共 3987 帧，720×720，透明 Alpha，源时间轴保持 1 倍速。
- 19 个 WAV 均为 48 kHz 双声道，与对应动画时长匹配（误差小于 3ms）。
- ZIP 与每个文件均记录 SHA-256；下载器在替换前验证整包、路径和逐文件哈希。
- 默认角色为内置妮可，素材目录不依赖白龙资源；更新仓库改为本项目，旧高清资源工作流已移出。
- 食物成功扣库存后仅播放编号 17「偷吃面包」。另一份 feed 保留为备用素材；两者不出现在随机和手动动作入口。
- 77 项功能、UI、视频工具、奖励、更新及素材安装检查通过；另有 3 项音频测试通过。另执行 43 项聊天测试，其中 4 项平台相关测试跳过，其余通过；代码编译及 diff 检查通过。
- macOS 原生窗口测试：前台为当前 ChatGPT/Codex 宿主，连续 56 次采样约 8 秒，状态刷新未改变前台进程；人物与气泡均保持可见且不接受键盘焦点。另外一轮 59 次采样同样保持可见且不抢焦点；主动打开设置后，原生窗口可激活并接受输入。

## 边界

这是 macOS Apple Silicon 上验证的源码版，不是验证过的 Windows EXE / macOS .app 安装器。继承的 Windows 构建代码不能当作本轮安装验收结果。

工作动作播放完整片段，不宣称无缝工作 Seam；不同生成视频的音色不保证完全相同。自动动作静音，主动声音仅在 1 倍速下播放。

Git 不包含密钥、用户配置、数据库、原视频、API 回执和真实桌面截图；README 图片只展示角色素材。当前 Git 树已清理旧工具与旧说明，历史提交未改写。

## 干净源码首次运行

从待提交 Git 索引导出干净目录，在空资源目录通过安装脚本校验并解压 Release ZIP，再以独立空数据目录运行 `run.py --smoke-test`。版本 0.10.0，窗口可见，资源数 27，解码错误为空，进程正常退出；不依赖原白龙资源或已有角色配置。

## 本机性能采样

macOS Apple Silicon，源码运行、720px 素材、512px 解码，关闭日志监控的隔离测试：预热后待机采样 6 秒，平均 CPU 为单核的 31.2%，RSS 249.4 MiB；隐藏后采样 3 秒，CPU 0.5%，动画计时器停止。短时单机结果不代表所有设备或开启完整监控后的负载。
