# 饱腹度与食物

角色右键菜单或托盘右键菜单 → **食物**，可查看饱腹度、面包数量及下一份奖励的 token 进度。点击“面包”喂食。

- 初始饱腹度 100%，每满 5 分钟下降 1%，最低为 0%。关闭程序和电脑休眠期间也计时；重启不会重置。运行中每 10 秒检查一次。
- 降到 30% 或以下时显示“主人～ 我好饿～”。同一次饥饿只提醒一次，喂到超过 30% 后再次下降才重新提醒。气泡隐藏、正在编辑面板或优先展示任务完成消息时，提醒保留到状态气泡可见；食物栏也显示饥饿台词。不会自动打开被手动隐藏的气泡。
- 每新增 1,000,000 token 获得 1 个面包，余数继续累计。一份面包恢复 30 个百分点，上限 100%；已吃饱或没有面包时不扣库存。
- 首次启用功能时记录起点时间，历史用量不补发。奖励范围与现有 Token 图表相同，使用所有月份的累计总量，不随月份或图表筛选重置；缓存输入不额外重复相加。不能统计未同步到本机的其他设备用量，亦不代表计费金额。
- 后台约每 30 秒扫描一次用量。按启用时间之后成功解析的 token 记录累计；部分旧日志不可读也不阻塞奖励，补读启用之前的旧记录不发奖。完全不可用时等待恢复，恢复后补算新增差额。重复扫描、重启和旧快照不会重复发奖；不同 Codex 数据目录分别去重。
- 更换角色共用当前桌宠的饱腹度和食物。数据存储在当前 `STATE_DIR` 下的 `pet-care.sqlite3`，与素材和设置文件分开；只有计数与来源标识，没有会话文本或密钥。
