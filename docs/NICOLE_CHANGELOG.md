# 妮可更新记录

## 0.10.1 · Codex 输入焦点修复

- 修复 macOS 运行检测误判 Codex 已关闭，导致状态事件交替展开、收起面板。
- 工具调用只更新状态；已收起的面板由用户点击展开，任务运行期间保持形态。
- 状态窗口默认不接收键盘焦点，聊天与设置仍可主动打开并输入。
- 不更换素材，不重置设置、面包库存或聊天记录。

## 0.10.0 · Seedance 连续视频版

- 将妮可设为默认内置角色，完全使用 Seedance 连续视频生成的透明 WebP；保留 27 段素材、3987 帧和 19 段音轨。
- 加入饱腹度、30% 饥饿提醒、每百万新 token 一个面包、库存持久化与奖励去重。
- 喂食成功后固定播放「偷吃面包」，禁止通过随机或手动动作触发。
- 接入主动互动声音，切换/隐藏/静音即停止；自动动作不发声。
- 修复 macOS 切换前台应用时工具窗口消失、状态刷新反复抬高窗口的问题，避免打断用户输入。
- 面板使用当前角色名，聊天存储 ID 与显示名分离。
- 独立运行数据与更新来源；新增带完整 SHA-256 校验的素材安装工具。
- 当前发布目录只保留 Seedance 制作路线；旧生图脚本、旧报告和旧截图归档到本地，不纳入本次发布。
