# 妮可更新记录

## 2026-10-25：发布准备

### 角色与生成工具

- 新增粉发猫娘妮可，使用新版 Q 版参考图和基准图锁定身份与服装。
- 新增 Seedream 客户端、25 动作提示词、阶段模式与完整帧模式；支持 dry-run、指定动作/帧区间、请求重试及回执。
- 默认关闭生成接口水印。已有图片的 API 输出格式与透明通道必须实际检查；提示词本身不保证 Alpha。
- 目前齐备 25 个动作的 2,875 张逐帧图片，数量检查通过。

### 饱腹度与面包

- 初始 100%，每 5 分钟扣 1%，离线继续计时，最低 0%。
- 到 30% 时提示「主人～ 我好饿～」，在同一次饥饿期间去重。
- 每新增 100 万本机 Codex token 发放 1 个面包；每份恢复 30%，最高 100%。
- 角色和托盘增加食物入口；库存、饱腹度、余数与来源去重信息通过数据库事务保存。
- 奖励只统计启用后的成功解析记录；历史部分不可读不阻塞新奖励，历史补读不计入新奖励。
- 40 项相关测试通过；macOS 原生菜单点击验证 40% → 70%、面包 1 → 0。

### 打包修复

- 修复 `nicole-idle-frame-083-01.png` 被误按样本后缀 `01` 排序，改为读取 `frame-083` 的帧编号。
- 编码前检查所有选中动作的完整序列，拒绝缺帧、重复帧和额外帧。
- 41/42ms 按累计时间均匀分配，保持动作总时长。
- 默认压缩等级从 6 改为 1，仍为无损；新增逐动作进度、耗时、帧数和体积输出。
- 文件通过临时文件编码/验证后再替换；逐动作保存校验回执，支持复用完成结果。
- 取消从最初几帧随意生成并标记为无缝的工作循环；待专门设计后启用。

### 尚未达到的目标

- 逐帧独立生图出现表情、轮廓与道具变化；“数量/帧率一致”不能作为“与白龙同等流畅”的证明。
- 全量动画视觉验收、可用的工作无缝循环、跨动作自然衔接仍未完成。
- 面向新用户的一键安装、默认妮可入口和独立更新源尚待发布验证。
